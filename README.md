# Acoustic Triangulator

Acoustic Triangulator — проект по моделированию акустической системы обнаружения БПЛА по данным трёх направленных станций. В локальной копии объединены Arduino-скетч станции, WPF-приложение визуализации и консольный Python-скрипт для геометрического расчёта координат.

## ✨ Возможности

- Моделирование расположения цели по данным трёх станций.
- Визуализация результата в WPF-приложении `Triangulator`.
- Ручной ввод длины стороны треугольника, углов возвышения и азимута для каждой станции.
- Arduino-скетч для поворота двух сервоприводов и поиска максимума сигнала с микрофона на входе `A0`.
- Отдельный Python-скрипт для вычисления медиан и точки их пересечения.

## 🚀 Быстрый старт

### WPF-приложение

```bash
cd Acoustic-triangulator
dotnet build Triangulator/Triangulator.csproj
dotnet run --project Triangulator/Triangulator.csproj
```

### Python-скрипт

```bash
cd Acoustic-triangulator
python "Триангулятор.py"
```

### Arduino-часть

Файл `station.ino` предназначен для открытия в Arduino IDE. Отдельная команда прошивки в проекте не указана.

## 📁 Структура проекта

- `Triangulator/` — WPF-приложение на C# для визуализации результата триангуляции.
- `Triangulator/TriangulationMath.cs` — расчёт пересечения направлений и высоты цели.
- `Triangulator/MainWindow.xaml` — интерфейс панели управления и карты.
- `station.ino` — скетч Arduino для работы с сервоприводами и микрофоном.
- `Триангулятор.py` — консольный расчёт медиан и центра треугольника.

## 🛠 Использование

WPF-приложение запускает визуальную панель, где можно менять:

- длину стороны треугольника;
- угол возвышения (`ELEV`) для каждой станции;
- азимут (`AZIM`) для каждой станции.

После изменения параметров приложение пересчитывает:

- координаты цели по осям `X` и `Y`;
- среднюю высоту объекта;
- статус пересечения лучей.

Скрипт `Триангулятор.py` последовательно запрашивает координаты трёх точек (`X1`, `Y1`, `X2`, `Y2`, `X3`, `Y3`) и выводит:

- точки пересечения медиан со сторонами;
- точку пересечения медиан.

Скетч `station.ino`:

- использует библиотеку `Servo.h`;
- управляет сервоприводами на пинах `11` и `10`;
- читает сигнал с аналогового входа `A0`;
- отправляет значения в `Serial`.
